Delete:DML
Using to delete the all records or specfic record.
You can rollback the delete operations before commit.
Structure of table is not deleted.
Syntax:delete tablename;
		delete tablename where condition;
		
Truncate:DDL 
Using to delete the all records permanently.
You dont have the rollback option.
Structure of table is not deleted.
Syntax:truncate table tablename;

Drop:DDL 
Using to drop command, delete all records along with structure permanently.
You dont have the rollback option.
Structure of table is also deleted.
Syntax:drop table tablename;
